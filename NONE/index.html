상세 요구사항 및 핵심 기능 구현

2.1 우클릭 드래그 지도 탐색

일반 마우스 좌클릭뿐만 아니라 **마우스 우클릭(오른쪽 버튼)**을 누른 채 드래그하여 자유롭게 지도를 이동할 수 있는 유연한 지능형 지도 드래그 탐색 지원.

2.2 개편된 사용자 위치 시스템

위치 미제공 시 **서울특별시 기본 좌표(37.5665, 126.9780)** 세팅. 사이드바 '위치 변경' 버튼 클릭 시 커서 핀 모드가 활성화되어 클릭 좌표로 즉시 변경됩니다.

2.3 다색 파이 차트 클러스터링

시설A가 포함된 뭉친 마커 구역은 `conic-gradient` 비율 파이 차트로 표기됩니다. (시설B만 포함 시 파란색 단색 표기, 내부 검은색 채색 금지 규칙 적용)

2.4 CCTV 설치 여부 시각화

CCTV 설치(Y) 구역 마커는 **진한 슬레이트 블랙 테두리 (`#0f172a`, 2.5px)**가 적용되며, 미설치(N) 시설 마커는 테두리가 없어 직관적으로 구별 가능합니다.

2.6 필수 마커 상세 팝업

마커 클릭 시 **대상시설명, 도로명주소(지번주소), 보호구역도로폭, 관할경찰서명, 관리기관명** 5가지 필수 데이터 및 CCTV 상세대수를 투명하게 제공합니다.

2.7 반경 확장 레이더 탐색

5km~20km 반경을 지정 후 레이더 탐색 시 시각 원 애니메이션이 펼쳐지며 지정 시설 외 마커는 일시 숨김 처리됩니다. '확인' FAB 버튼으로 복구가 가능합니다.
